## Cómo descargar el archivo de Excel

**Opción rápida:** haz clic en este enlace y el archivo se descarga directamente:
https://github.com/ricgoitia/valoracion-empresas-femsa-valora/raw/main/FEMSA_Valora_calculos.xlsx

**Desde GitHub:**
1. Haz clic en `FEMSA_Valora_calculos.xlsx` en la lista de archivos.
2. Haz clic en los tres puntos (**···**) de la esquina superior derecha y elige **Download**.
   También puedes usar el ícono de descarga (flecha hacia abajo) que está a la derecha del botón "Raw".
3. Abre el archivo con Excel.
